Kalup 1.0 release candidate. Nothing changes from 0.6.0 for a project or a script: this release starts the candidates for 1.0.0, which freezes the contracts in docs/compatibility.md (the config grammar, commands and flags, `--json` output, exit codes, issue codes, and the state, plan, IR and blueprint formats). From 1.0.0, within 1.x they only grow. A release candidate may still change one of them if a problem turns up, and its notes say so. Install a candidate with `npm install -D kalup@rc` and `npm install @kalup/core@rc`; `latest` stays on 0.6.0 until 1.0.0.
