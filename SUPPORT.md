# Getting help

Start with the docs. Most questions about config files, pull and keys are answered there.

1. **Docs.** The [README](README.md) for the overview, then the user docs that ship with the CLI: [config files](packages/cli/docs/config.md), [pull](packages/cli/docs/pull.md) and [targets and keys](packages/cli/docs/targets.md). Most errors in the output name a fix; with `--json` it is in `issues[].fix`.
2. **Questions and ideas: [GitHub Discussions](https://github.com/scopiousdigital/kalup/discussions).** How do I model this property, is this planned, does this fit the roadmap. Search first; someone may have asked.
3. **Bugs: [GitHub issues](https://github.com/scopiousdigital/kalup/issues/new/choose).** Something does not work as the docs say. The bug form asks for what we need to reproduce it.
4. **Coverage requests: [the resource request form](https://github.com/scopiousdigital/kalup/issues/new?template=resource_request.yml).** A HubSpot asset type you want Kalup to manage.
5. **Security problems: [SECURITY.md](SECURITY.md).** Report privately, never in a public issue.

Before you post, remove keys, tokens, real portal IDs and client data. Invented names work as well.

Kalup is maintained part-time, so answers can take a few days. Problems with your HubSpot account, billing or permissions belong with HubSpot support.
