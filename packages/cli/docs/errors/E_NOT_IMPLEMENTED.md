# E_NOT_IMPLEMENTED

The command is planned but not in this version. Exit 1.

## When

`kalup --help` marks these commands `(not implemented yet)`: `compare`, `plan`, `snapshot`, `docs` and `apply`.

## Fix

Use the commands this version has: `init`, `pull`, `validate`, `ir`, `fmt` and `status`.

## Example

```
E_NOT_IMPLEMENTED: kalup plan is not implemented yet (docs: errors/E_NOT_IMPLEMENTED.md)
```
